# Data

The CLANAK dataset is intentionally not duplicated in this source-code repository.

Authoritative archive:

- Zenodo: https://doi.org/10.5281/zenodo.22151093

Corresponding Kaggle copy:

- Kaggle: https://doi.org/10.34740/kaggle/dsv/19509973

The dataset contains the four source CSV files used by the analysis code:

- `sunrise_normal.csv`
- `sunrise_attack.csv`
- `sunset_normal.csv`
- `sunset_attack.csv`

Download the dataset from the archive and upload/place the files according to the instructions in the individual component README files.
