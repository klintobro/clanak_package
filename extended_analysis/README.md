# CLANAK extended analysis

**Original execution environment:** Google Colaboratory (Google Colab).

Open `CLANAK_Extended_Analysis.ipynb` in Google Colab and run the cells sequentially. The notebook expects the four CLANAK CSV files and uses the Colab file-upload interface.

The supplied 38-cell master code includes descriptive statistics, hypothesis tests, normality/variance checks, effect and association analyses, environmental PCA/OLS analyses, conventional machine-learning benchmarks, ELM-110, LSTM-128, and the ELM110-LSTM128 unanimous ensemble.
